# Personal Portfolio Website

A responsive portfolio website showcasing skills in data science, machine learning, IT, software development, and consulting.

## Features

- Responsive design that works on all devices
- Sections for About, Skills, Certifications, Projects, and Contact
- Modern, clean UI with smooth scrolling navigation

## Hosting on GitHub Pages

To host this website for free on GitHub Pages:

1. Create a new repository on GitHub (e.g., `yourusername.github.io`)
2. Upload all files from this project to the repository
3. Go to Settings > Pages in your repository
4. Under Source, select "Deploy from a branch"
5. Select the main branch and click Save
6. Your site will be available at `https://yourusername.github.io`

## Customization

- Replace "Your Name" in `index.html` with your actual name
- Update contact information in the Contact section
- Add your actual projects and details
- Modify colors and styles in `styles.css` as needed
